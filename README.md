# Laura Yoga

A single-page marketing site for Laura's online yoga classes, taught live via Zoom.

## Structure

- `index.html` — page content (hero, about, classes, schedule, pricing, contact)
- `css/style.css` — styling
- `js/main.js` — mobile nav toggle, footer year

All bio, schedule times, and prices are placeholders — update before going live.

## Local preview

```bash
python3 -m http.server 8091
```

Then open `http://localhost:8091`.
